# Бизнес-симуляция «Экспансия»

Стратегическая игра для сотрудников банка. Команды играют за правления банков-конкурентов: четыре игровых года они выходят в регионы, делят рынок и отвечают за результат своих решений. Развёрнута из игры «Экспансия» каталога бизнес-игр.

| | |
|---|---|
| Аудитория | Сотрудники банка из любых подразделений |
| Группа | 12–30 человек, 3–6 команд по 4–5 человек |
| Время | 4 часа |
| Ведущий | Один; при 5–6 командах нужен помощник за ноутбуком |
| Что развивает | Системное мышление, решения при нехватке данных, нацеленность на результат, командную работу |

## Файлы

| Файл | Что это | Когда нужен |
|---|---|---|
| `1_Rukovodstvo_vedushchego.pdf` | Руководство ведущего: устройство игры, подготовка, сценарий по минутам, разбор | Прочитать заранее |
| `2_Razdatochnye_materialy.pdf` | Досье рынка, правила, роли, бланки, обзоры рынка, анкета, листы ведущего. На первой странице — ведомость печати | Распечатать за день-два |
| `3_Slaydy.pptx` | 34 слайда. В заметках к слайдам — слова ведущего | Показывать на игре |
| `4_Kalkulyator_vedushchego.xlsx` | Калькулятор без макросов: считает итоги каждого года по решениям команд | Открыт на ноутбуке всю игру |

## С чего начать

1. Прочитайте в руководстве части 1 и 2.
2. Откройте калькулятор и введите пробную партию из части 3 руководства. Сверьте итог.
3. Проговорите вслух объяснение правил по слайдам 4–14.
4. Распечатайте материалы по ведомости и соберите папки команд.

## Что важно знать

- Игра не обкатана на живой группе. Экономика сбалансирована расчётом на модели, время блоков расчётное. Перед первой игрой сыграйте один год с коллегами.
- Слайды сделаны на основе шаблона «We build Products» в цветах банка. Шрифт слайдов — Inter, как в шаблоне. Если он не установлен, PowerPoint подставит системный шрифт.
- Калькулятор сверен с эталонной моделью (`src/game.py`) на случайных партиях для 3–6 банков, пересчёт выполнялся в LibreOffice. Перед игрой откройте его в Excel на рабочем ноутбуке.
- Банк, регионы и события в игре вымышлены.

## Как пересобрать

Числа игры заданы в `src/game.py`, тексты — в `src/content/texts.py` и в файлах сборки.

```
cd src
python3 build_all.py        # всё сразу
python3 verify_xlsx.py /tmp # сверка калькулятора с моделью
```

Нужны Python с пакетами `openpyxl`, `python-pptx`, `Pillow`, а также Node.js с Playwright (для PDF) и LibreOffice (для сверки и скриншотов). Основа слайдов `src/assets/base.pptx` получена из исходного шаблона скриптом `src/make_base.py`.
