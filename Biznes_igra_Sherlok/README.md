# Бизнес-игра «Шерлок. Дело о платеже № 318»

Игра-расследование для сотрудников банка. Развёрнута из игры «Шерлок» каталога бизнес-игр: аналитическое мышление, внимание к деталям, решение сложных задач, логическое обоснование выводов, командная работа.

| | |
|---|---|
| Аудитория | Сотрудники банка из любых подразделений |
| Группа | 8–25 человек, 2–5 команд по 4–5 человек |
| Время | 3 часа |
| Ведущий | Один, опыт не нужен |

## Что в папке

| Файл | Что это | Когда нужен |
|---|---|---|
| `1_Rukovodstvo_vedushchego.pdf` | Руководство ведущего: подготовка, сценарий по минутам со словами ведущего, разгадка, дебриф, оценка результата | Прочитать заранее, держать в руках на игре |
| `2_Razdatochnye_materialy.pdf` | 15 документов дела, бланки, карточки, ключ. На первой странице — ведомость печати | Распечатать за 2–3 дня |
| `3_Slaydy_dlya_ekrana.pdf` | 24 слайда для проектора | Показывать на игре |
| `src/kit.html` | Страница-комплект: то же руководство, документы дела и слайды с таймером раундов | Читать с экрана, вести игру с ноутбука |

## С чего начать

1. Прочитайте в руководстве части «Обзор» и «Сценарий» — 30 минут.
2. Решите дело сами по раздаточным материалам (стр. 3–18), не заглядывая в ключ, — 60–90 минут.
3. Распечатайте материалы по ведомости и разложите по конвертам.
4. Проговорите вслух открытие и правила.
5. Проведите игру по сценарию.

Разгадка дела есть в руководстве (часть 4) и в ключе ведущего (раздаточные материалы, стр. 29–30). Не показывайте её участникам до разбора.

## Как пересобрать

Тексты лежат в `src/content/`, оформление — в `src/styles/`. После правок:

```
node src/build.mjs
```

Нужны Node.js и Playwright с Chromium. Время, номера документов, телефоны и фамилии в деле связаны между собой: меняя одно, проверьте остальные документы и ключ.

Банк, организации, люди, суммы и телефонные номера в игре вымышлены. Шрифты Golos Text, Oswald и JetBrains Mono распространяются по лицензии SIL Open Font License 1.1.
