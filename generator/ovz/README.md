# Курс ОВЗ (счета нерезидентов) — новый дизайн

Редизайн курса «Открытие, ведение и закрытие банковских счетов физических лиц-нерезидентов»
в фирменном стиле Ipak Yuli Bank. Меняется только оформление: текст, заметки, ID слайдов,
гиперссылки, morph-переходы и объекты iSpring (интерактивы, тесты) остаются как в исходнике.

Сборка (нужен исходный файл курса):

```bash
mkdir -p src && python3 -c "import zipfile,sys; zipfile.ZipFile(sys.argv[1]).extractall('src')" ИСХОДНЫЙ_КУРС.pptx
python3 build.py src assets out [ref]    # перекраска, фоны, иллюстрации; ref — распакованная прежняя версия курса,
                                         # если номера картинок в новой версии сдвинулись
python3 pack.py out OVZ_new.pptx         # упаковка
python3 verify.py ИСХОДНЫЙ_КУРС.pptx OVZ_new.pptx   # текст 1:1, заметки, ссылки, iSpring
```

`assets/` — готовые фоны, персонаж-гид, иллюстрации шагов (цвет и ч/б для индикатора прогресса),
логотипы. Исходники иллюстраций сгенерированы в Magnific (проект «Ipak Yuli — курс ОВЗ (нерезиденты), редизайн»).
`make_assets.py` собирает `assets/` из этих исходников.

Текст курса — свежая редакция (файл «…_1.pptx», сохранён 17.11.2026, положение от 22.06.2026).
Файл «ОВЗ банковских счетов для нерезидентов.pptx» от 16.09.2025 — старая редакция (положение от 09.12.2022).
Служебные метки iSpring у обеих версий и у собранного файла одинаковые байт в байт, поэтому собранный файл
кладут под именем «ОВЗ банковских счетов для нерезидентов.pptx» рядом с папкой проекта «…_1».
