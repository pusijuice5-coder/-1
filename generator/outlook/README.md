# Электронный курс «Outlook: почта и календарь»

Генератор собирает `Outlook_kurs_pochta_i_kalendar.pptx` (79 слайдов) из Python-описания.

```
python3 generator/outlook/build.py Outlook_kurs_pochta_i_kalendar.pptx
```

| Файл | Что внутри |
|---|---|
| `lib.py` | Построитель слайдов: фигуры, стеклянные карточки, переход «Трансформация» (Morph), анимации появления, триггеры по щелчку, гиперссылки, заметки |
| `kit.py` | Общие детали: шапка и навигация, карточки, сетки, шаги, сравнения, тестовые вопросы, заставки модулей |
| `mock.py` | Схематичные окна Outlook (почта, новое письмо, календарь, собрание, помощник по планированию) из обычных фигур |
| `m0.py … m6.py` | Содержание: вступление, пять модулей, финал с тестом |
| `base/` | Пустой пакет презентации (тема, макеты, образец заметок) |
| `assets/` | Фоны-свечения, 3D-объекты, линейные значки, логотип |
| `r3d/`, `prep_icons.js` | Как получены 3D-значки (three.js) и линейные значки (Lucide) |

Как устроена анимация: у каждого объекта имя начинается с `!!`. Одинаковые имена на соседних слайдах
«Трансформация» плавно переводит друг в друга (рамка-подсветка, меню шагов, фон), уникальные — просто проявляются.

Шрифт — Segoe UI (есть на каждом компьютере с Windows). Тексты диктора лежат в заметках к слайдам.
