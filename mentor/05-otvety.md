## Формулы и модели

- **Шаблон гипотезы:** Мы верим, что [изменение] для [аудитории] приведёт к [результату]. Поймём, что правы, когда [метрика] изменится на [величину].
- **Видение продукта:** Продукт [ ] для [ ], который решает проблему [ ] с помощью [ ].
- **Пользовательская история:** Как [роль], я хочу [действие], чтобы [ценность].
- **INVEST:** Independent (независимая), Negotiable (обсуждаемая), Valuable (ценная), Estimable (оцениваемая), Small (небольшая), Testable (проверяемая).
- **Приоритет** = ценность / трудозатраты.
- **RICE** = Reach × Impact × Confidence / Effort (оценки 1–10). Пример курса: 8 × 5 × 5 / 1 = 200; 3 × 10 × 1 / 10 = 3.
- **Доверие** = (открытость + профессионализм + надёжность) / личный интерес.
- **SBI:** Situation (ситуация) → Behavior (поведение, только факты) → Impact (влияние).
- **DoR → AC → DoD:** вход в спринт → содержание задачи → выход из работы.

## Сокращения, о которых спросят

| Сокращение | Расшифровка |
|---|---|
| PO | Product Owner — Владелец продукта |
| SM | Scrum Master — скрам-мастер |
| TM | Team member — участник команды |
| CL | Competence Lead — лидер компетенций |
| MVP | Minimum Viable Product — минимальная жизнеспособная версия продукта |
| DoR / DoD | Definition of Ready / Done — критерии готовности к работе / завершённости |
| AC | Acceptance Criteria — критерии приёмки |
| WIP | Work In Progress — работа в процессе (лимит задач «в работе») |
| P&L | Profit and Loss — отчёт о прибылях и убытках |
| NPS | Net Promoter Score — готовность клиента рекомендовать |
| CSI | Customer Satisfaction Index — индекс удовлетворённости клиентов |
| MAU | Monthly Active Users — активные клиенты за месяц |
| ARPPU | Average Revenue Per Paying User — средний доход на платящего клиента |
| EBITDA | Прибыль до вычета процентов, налогов и амортизации |
| ROI | Return on Investment — окупаемость вложений |
| CIR | Cost-to-Income Ratio — отношение расходов к доходам |
| Retention | Удержание клиентов |
| Time to market | Время от идеи до выхода к клиенту |
| Lead time | Время прохождения задачи от появления до готовности |
| T-shaped | Глубокая экспертиза плюс понимание смежных областей |
| Kick-off | Стартовая встреча запуска команды |
