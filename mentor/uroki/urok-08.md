### 0:17 Практика RICE (15 минут)
**Группы по 3–4, 8 минут.** В чат:
> Оцените 4 идеи по шкале 1–10 и посчитайте **R × I × C / E**. Какая идея первая?
>
> | Идея | R охват | I влияние | C уверенность | E усилия | RICE |
> |---|---|---|---|---|---|
> | Онлайн-запись в отделение через приложение | | | | | |
> | Push-уведомление за 3 дня до платежа по кредиту | | | | | |
> | Новый дизайн всех экранов приложения | | | | | |
> | Чат-бот для 10 самых частых вопросов | | | | | |

**Правильного ответа нет.** Ценен разговор. После групп (7 минут) спросите:
- «У кого какая идея на первом месте? Почему разошлись?»
- «Где вы были меньше всего уверены (C)? Как повысить уверенность?» (Мостик к гипотезам и MVP!)

Обычно push-уведомление получает высокий балл (большой охват, мало усилий), а «новый дизайн всех экранов» низкий (огромные усилия).

### 0:40 Квиз «Какое событие?» (5 минут)
> 1. 15 минут каждый день, сверка прогресса к цели
> 2. Команда показывает результат пользователям и собирает отзывы
> 3. Команда выбирает 1–2 улучшения своего процесса
> 4. Определяют цель спринта и выбирают задачи
> 5. Уточняют, разбивают и оценивают будущие задачи

**Ответы:** 1 — ежедневный Scrum, 2 — обзор спринта (демо), 3 — ретроспектива, 4 — планирование, 5 — актуализация бэклога.

Вставьте: «Кстати, в конце каждой нашей встречи мы делаем мини-ретро. Это тоже пункт 3».

## Если спросят
- **«DoR, AC, DoD — путаюсь»** — вход, содержание, выход. DoR: можно ли брать в спринт. AC: что умеет конкретная история. DoD: единое «готово» для всех задач.
- **«Кто оценивает ценность, а кто усилия?»** Ценность — PO, трудозатраты — команда.
- **«Ежедневный Scrum — это отчёт?»** Нет, это синхронизация команды на 15 минут.
- **«Можно ли совмещать Scrum и Kanban?»** Да, многие команды используют Kanban-доску внутри спринта. Базовый фреймворк agile-команд банка — Scrum.
