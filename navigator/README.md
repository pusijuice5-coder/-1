# Пульт навигатора: «Трансформация продаж»

`pult-navigatora.html` — страница для навигатора-ведущего по памятке навигатора:

- **Перед сессией**: техника, настройка себя, фразы для начала урока.
- **Как вести**: принципы, вопросы вместо оценок, молчание, сопротивление.
- **Сообщения и ДЗ**: проверка фонового задания по 4 пунктам и шаблоны сообщений с подстановкой имён.
- **Уроки 1–5**: таймкоды с тем, что сказать на каждой паузе, повторами фрагментов и правильными ответами. Полоса сверху показывает следующую паузу.

Уроки 6–10 добавятся, когда будут подсказки из методички.
